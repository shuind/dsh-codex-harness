# 预设与提示词

适用于插件 `0.3.1` 和 DeepSeek Harness `0.2.2-rc.1`–`0.2.2-rc.5`。

## 当前入口

打开 **设置 → 内置插件 → Codex Harness**。页面分为“预设方案”和“运行偏好”：前者管理当前选中预设的工具控制（启用 / 替换 / 延迟 / 隐藏）、提示词覆盖与只读原始 YAML；后者编辑当前配置环境共享的模型请求与显示偏好。插件详情仅提供摘要和设置路径，不再复制另一套完整表单。

## 原始定义只读，提示词覆盖可编辑

当前 `agentPresets` 服务提供声明列表和 YAML 查看，不提供目录路径、复制或删除接口。因此，本插件不把原生预设伪装成可写源文件，也不为只读声明提供假保存或复制操作。

“提示词”子视图读取当前预设原有的指令段。可核验的原生身份前缀/后缀和 Codex 操作指南支持独立覆盖；无法确认来源、完整性或覆盖语义的其它段只读。不会把 YAML 标签或表达式当正文，更不会给非 Codex 预设填入一份共享 Codex 模板。

修改存到该预设的 `promptOverrides`，不写原始定义。每段“恢复原始”只移除对应覆盖；工具配置、其它指令段和其它预设不变。覆盖在新建或重载 Agent 时按快照加载，保留原有 complete、插值和位置语义，不替换工具声明或宿主运行约束。

旧共享模板数据保留后台兼容；没有独立覆盖的预设维持原来的指令，不自动迁移成每个预设一份，也没有共享模板编辑页面。需要改变插件组成时，仍使用 Harness 的 Creator/自定义 bundle。

工具选择与执行/计划替换同样无需修改预设声明，详见 [跨预设工具覆盖](tool-policy.md)。工具选择本身不改身份指令；提示词仅在用户明确编辑该预设对应段时覆盖。

## 本仓库的声明来源

- [原始组合](../presets/codex-hybrid/agent.cordis.yml) 保存 **Codex 混合模式** 预设的工具、延迟加载与提示词配置。
- [适配器](../src/presets/desktop-preset.ts) 转换旧工作流名称、子代理配置，并移除已退役的 `list-agents` 子路径；不会执行 YAML 中的 `!!js`。
- [生成脚本](../scripts/build-preset.mjs) 在构建时产生 [bundle patch](../cordis.patch.yml)，其中的普通声明行 id 为 `preset-codex-hybrid`，会话预设 id 为 `codex-hybrid`。

不要手动修改生成的 patch，也不要直接改安装目录或 profile。通过 bundle 覆盖声明时，`config` 是完整替换，必须保留所需的 `id`、名称、说明及完整 `plugins` 列表。服务提供者和消费者的隔离组应保持完整。

## 旧目录预设

历史版本曾使用 `$DSH_HOME/.agent-presets/<id>/` 中的 `preset.yml` 和 `agent.cordis.yml`。当前宿主不再读取这个目录，本插件也不会在启动时覆盖、迁移或删除它。

如需迁移自定义内容，先备份旧目录，再通过 Creator/自定义 bundle 将元数据和插件列表迁成普通预设声明，检查插件名称和 Config 是否符合当前宿主接口。不要仅把目录复制到新安装中；也不要用版本豁免加载旧插件。
